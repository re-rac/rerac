# Test request: the Port Options strafe (2026-10-04)

`cargo dev`, then pause → Options → Port Options → "Strafe (L2 / R2)" On (or start with `RC_STRAFE=1`).

### S1. Off by default
- **Claim:** with the setting off (a fresh settings file), L2 still gives the look stance and R2 still crouches, as in
  the original.

### S2. Strafing
- **Claim:** with it on, holding L2 or R2 turns Ratchet to face where the camera looks and keeps him facing it while
  the left stick moves him in any direction at the usual walk / run speed. Letting go turns him back to normal
  running. L1 still gives the look stance and R1 still crouches.
- **Known look:** RaC1 has no side-step animations, so his walk / run cycle plays whichever way he moves.

### S3. Strafe flips
- **Claim:** while strafing, ✕ with the stick to a side or back flips that way (the original side / back flip), and
  pressing ✕ again on landing chains another flip while the button is held. ✕ with the stick forward is a normal jump.

### S4. Elsewhere
- **Claim:** the Thruster-Pack hover still turns to the camera with L2 / R2; the Hoverboard's L2 / R2 tricks and Clank's
  and Giant Clank's controls are unchanged; the setting survives a restart.
