# The utility gadgets (Hydrodisplacer, Trespasser, Metal Detector, Hologuise, PDA) and their puzzles

## 1. Summary

- **Five hand items as `HAND_ITEMS` rows** on the shared hand-item system (`rc-game/src/hero/gadgets.rs`):
  - Hydrodisplacer 22 (class 1251, update L01 `0x309cd0`): the use poses 0x38..0x3a on the pads 341, the water command
    8 / 4 to the pad's linked water moby, the cutaway between the pad's two camera cuboids (fade, letterbox, camera
    spring), the hold of 100 ticks on pads without cameras, the full gadget's drip (type-35 drops) and bulge (the hand
    records).
  - Trespasser 26 (class 188, update `0x2d7380`): ○ held → its +0xbc = 1 (`Gadgets::item_bc`), read by the locks 615.
  - Metal Detector 27 (class 585, update `0x2f2280`): the head's aim toward the nearest buried cache 605, the beep loop
    with its pitch, the item colour, the dig (the cache pays out as 5-bolt bolts, one save-nibble dig per bolt, the
    cache deleted, class sound 3), the scan rings (draw callback `0x2f1e28`).
  - Hologuise 31 (hand moby class 483; weapon-check case 0x1f, request 0x1f): the 18-tick timer, voices 0x18 / 0x19, the
    squash, the disguise moby 0x27a and **body 3** (states 0x53..0x59) on the shared body system, its tint and glow
    quads, the ways out (□, another item, a magnetic floor with the Magneboots, any state outside the disguise's).
  - PDA 32 (class 619; weapon-check case 0x20): `OpenVendorMenu(0)` → the hand-off `Handoff::OpenVendor { vendor: None }`
    (the menus lane's remote vendor presentation does the rest).
- **Puzzle classes**: the Trespasser lock 615 (census U96, 7 levels, 19 instances, L02 `0x2d8ad0`) with its whole
  minigame (camera, hold 0x72, pull, rings, input, solve rule, fail / exit, sounds, death bits, open state 4) and its
  draw callback `0x2d93e8` laid out as 2-D primitives; the doors it opens: 743 / 744 (L02, U107 / U108) and 1159 (L11,
  U365, also opened by a floor switch 830). The Hydrodisplacer pads 341 (U170) were ported before; their sender is now
  live.
- **Shared parts added (plug-and-play)**:
  - the hand records 0x140c40 (`Gadgets::hand_joints`, kind 5, run by the slot loop through `0x227050`:
    `gadgets::hand_records`) and the hand moby's modifier list (`Gadgets::hand_mods`, drawn by `rc-engine`
    moby_attach); a new item writes joint / k / d / scale / translation targets of a record;
  - item → hero calls inside the slot loop (`gadgets::ItemCall::{SetState, SetAnim}`, run by `gadgets::after_items`);
  - `Gadgets::item_bc` (the hand moby's +0xbc that classes read); `Gadgets::released_or` (writes into the pad's
    released mask); `Gadgets::game_mode` (0x15f5c4 for the hero code, `MobySystem::game_mode`); `Gadgets::hand_saved` /
    `hand_request` (mirrors of 0x141660 / 0x141408 for the hero code outside the slot loop);
  - `HeroWorld::moby_pose` (`Carriers::ground`: the hero's ground moby's class / position / yaw for the physics);
  - `SoundCmd::ItemPitch` + `HeroSounds::set_pitch_bend` (an item loop's pitch bend);
  - `GameWrite::MetalDetectorDig` (the buried caches' save nibbles);
  - draw callbacks `DetectorScan` (fx_draw quads), `TrespasserRings` (scene_render 2-D), `DisguiseGlow` (fx_draw glow
    quads);
  - `fx::MobySpawn::Disguise` (the disguise moby, then the switch through `Bodies::restore`).
- **G-HERO-025 closed**: the holster check has no per-item cases (documented); the swap timers 0x13f52a / 0x13f52c are
  counted down in `post_move`; the def +0x20 write has no reader (n/a); the Suck Cannon's put-away ORs 5 into the pad's
  released mask while L1 / L2 are held.
- **Not done**: Clank's command menu G-UI-018 (facts recorded in gaps.md) and the gadgetbots 857.
