## How to use it

- **Gaps are systems.** A row names the shared game system that is missing (with its addresses when known) and lists
  the levels, objects and items that need it as **consumers**. A row of its own is kept only for real one-off content
  (a unique minigame, a boss, a class whose logic no other class shares); those sit under "Unique content", grouped by
  kind and tied to the systems they need.
- **Find work.** Pick rows by system or by the "Batch" column (rows that should go to one agent together).
- **Every agent updates this page** (orchestration.md §3.2):
  - add what it leaves unfinished: a new consumer on an existing system row, or a new system row with the next free
    ID of its section; name the missing shared system, and list the object or level only as a consumer;
  - mark what it closes: strike the consumer or the row (`~~…~~`) with "closed YYYY-MM-DD, <doc § or file>";
  - never renumber or reuse an ID; a merged ID goes to "Merged IDs" with its new home.
- **Don't guess.** A note that cannot be placed with confidence goes to "Needs triage" with its source.

**ID scheme.** `G-<SYS>-NNN`, numbered per section and never reused: `HERO` hero, `WPN` weapons and gadgets, `ENM`
enemies and creatures, `CLS` moby classes and the moby system, `REN` rendering (world, moby, effects, sky / sea), `PRT`
particles, `AUD` audio, `CUT` cutscenes and movies, `UI` menus, HUD and vendor, `SAV` progression and saves, `LVL`
levels and space, `LCH` launcher, `EXT` extractor and packaging, `MOD` mods, `TOOL` tooling and tests, `TRI` needs
triage. IDs absorbed by a system row are listed in "Merged IDs" at the end, so old references still resolve.

**Columns.** *System*: what it is in the game. *Consumers*: the levels, objects, items and features that need it (the
old per-instance gaps). *Absorbs*: old IDs folded in. *Sources*: doc § or `file:line` (paths under `crates/` shortened
to `<crate>/src/...`), or the orchestrator's log as "agent report DATE". Addresses are level01 unless marked (L00 =
level00, L03 = level03, boot = boot ELF). *Seen*: whether a player can see, hear or feel it (yes / no; "minor" = only
side by side). *Batch*: a suggested grouping for dispatch.

**Markers.**
- **[deferred]**: the user explicitly deferred it: space scenes, the hero feel pass, progression and saves, the
  profiling session (the in-game map screen was on this list; its system was ported 2026-09-28, G-UI-001); also mods ("document only for now") and the native Phase 2 pass ("later").
- **[in flight]**: an agent is working on it as of 2026-09-28: ~~guns (Blaster, Devastator, R.Y.N.O., Tesla Claw)~~ (closed 2026-09-28, G-WPN-001), moby
  ~~glow halos + chrome material~~ (closed 2026-09-28, G-REN-003), ~~open sea / liquid layers~~ (closed 2026-09-28, G-REN-001). The wrench zipline reported 2026-09-28: the cable slide 0x74
  on Kerwan works; its leftovers are consumers of G-HERO-027, G-CLS-001 (Kerwan's class 1342), G-UI-017 and G-SAV-009.
